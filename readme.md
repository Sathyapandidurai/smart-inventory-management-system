# Smart Inventory Management System

## 1. Project Overview

The Smart Inventory Management System is a Java Full Stack web application designed to help businesses manage products, monitor stock levels, record sales and track inventory performance.

The application provides a centralized dashboard for managing inventory operations efficiently.

## 2. Technologies Used

**Frontend**
- React.js
- JavaScript
- HTML5
- CSS3
- Axios

**Backend**
- Java
- Spring Boot
- Spring Data JPA
- REST APIs

**Database**
- MySQL

**Development Tools**
- Visual Studio Code
- Node.js
- Maven

## 3. Main Features

- Product Management – Add, view, update and delete products.
- Stock Management – Perform stock-in and stock-out operations.
- Low-Stock Alerts – Identify products below their minimum stock level.
- Sales Management – Automatically record sales during stock-out operations.
- Dashboard – Display inventory and sales statistics.
- Search and Filtering – Search products and filter by category.
- Product Sorting – Sort products by price and quantity.
- Business Reports – Display sales metrics and inventory value.
- Sales Performance Chart – Visualize sales revenue.

## 4. System Architecture

React.js Frontend → REST API → Spring Boot Backend → MySQL Database

## 5. How to Run

**Backend**
1. Open the inventory-backend folder.
2. Configure the MySQL database credentials.
3. Run the Spring Boot application using Maven.

**Frontend**
1. Open the inventory-frontend folder.
2. Install dependencies using `npm install`.
3. Start the application using `npm run dev`.

## 6. Project Outcome

The application successfully supports product management, inventory tracking, stock alerts, sales recording and business reporting through a web-based interface.
